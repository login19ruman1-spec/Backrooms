# Backrooms v11 — Paper 1.21.4

## Что добавлено
- Уровни 0–10, каждый с подуровнем `.1` (например `4` и `4.1`).
- Уникальный редкий уровень `EXIT`.
- Уровни размещаются по крупным регионам карты в псевдослучайном порядке, а не идут по очереди вдоль X.
- Порталы ведут на случайные уровни; шанс попасть на EXIT через портал — 1%, сам EXIT встречается крайне редко в процедурной карте.
- Команда `/br level <номер>` снова телепортирует OP: `/br level 0`, `/br level 4.1`, `/br level 10`, `/br level exit`. Также доступно `/backrooms level ...`.
- Чат-сообщения плагина о порталах и проломах показываются только операторам. Все команды доступны только OP.
- Лут увеличен: контейнеры получают 12–18 случайных предметных стеков плюс гарантированную записку; ресурсы соответствуют основному уровню, на EXIT пул редких предметов.

## Сборка
Java 21, Paper API 1.21.4. В GitHub Actions должен выполняться `gradle build`. JAR находится в `build/libs/`.

## Установка
1. Остановить сервер и сделать резервную копию мира.
2. Загрузить содержимое архива в корень репозитория.
3. Запустить GitHub Actions и скачать JAR из Artifacts.
4. Заменить старый JAR в `plugins/` и перезапустить сервер.

Важно: уровни строятся при генерации/загрузке чанков. Уже построенные чанки не перестраиваются автоматически после обновления. Тестировать на копии мира.


## NPC-клоны игроков (v12)
- Для настоящих NPC-моделей игроков и скинов требуется отдельный плагин **Citizens**, совместимый с вашей сборкой Paper 1.21.4. Backrooms объявляет его как необязательную зависимость: без Citizens основной генератор продолжает работать, но клоны не создаются.
- В `config.yml` есть `clones.enabled`, `clones.auto-track-players`, `clones.names`, `clones.max-npcs` и `clones.spawn-radius-chunks`.
- Имена `7gh`, `Alon`, `Voredishn` добавлены в список по умолчанию. Плагин также запоминает ники игроков, заходящих на сервер, в отдельном файле `plugins/Backrooms/players.yml`, не перезаписывая основной конфиг.
- Когда генерация Backrooms включена, NPC-клоны появляются в случайных местах в области вокруг начала Backrooms и используют скин соответствующего ника через Citizens.
- Ограничение `max-npcs` не даёт бесконечно создавать NPC. Если на сервере очень много игроков, увеличивайте лимит осторожно.

**Установка:** установите Citizens отдельно, затем поставьте собранный Backrooms JAR. Убедитесь, что `clones.enabled: true`; выполните `/br generate`. NPC не создаются без Citizens.


## v13: жуткое поведение NPC-клонов

- Клоны не защищены от обычного урона и их можно убить.
- Они периодически перемещаются по соседним комнатам/коридорам с разной скоростью.
- На близкой дистанции могут остановиться и смотреть прямо на игрока.
- Часть встреч заканчивается внезапным исчезновением; NPC возвращается спустя случайную паузу.
- Поведение работает только при включённой генерации и установленном Citizens.
- NPC не должны появляться постоянно рядом с игроком: появление и реакции выбираются случайно.
- Проверяй на копии мира; совместимость reflection-вызовов зависит от версии Citizens.
