# BackroomsPlugin — Paper 1.21.4

Плагин для существующего мира Paper 1.21.4. Java 21.

## Установка
1. Соберите проект через GitHub Actions (workflow `Build Backrooms plugin`) или локально командой `gradle build`.
2. Возьмите JAR из `build/libs/` или из артефактов GitHub Actions и положите в `plugins/`.
3. Запустите сервер, затем остановите его и настройте `plugins/Backrooms/config.yml`.
4. В `world-name` укажите точное имя папки уже существующего мира. Плагин не создаёт отдельный мир.
5. Запустите сервер и выполните команды от OP.

## Команды (только OP)
- `/br info` — состояние и имя настроенного мира.
- `/br generate` — включить генерацию в настроенном существующем мире.
- `/br stop` — выключить генерацию.
- `/br level 0|1|2` — справка о поиске порталов; команда не телепортирует напрямую.

## Механики
- Физические порталы появляются в случайных сгенерированных секциях, а не в фиксированном хабе. Подойди к порталу, чтобы перейти на следующий уровень (0 → 1 → 2 → 0).
- У каждого уровня своя палитра и декор: офисные остатки и жёлтые покрытия на уровне 0, индустриальные детали на уровне 1, тёмные материалы и души-фонари на уровне 2. Комнаты бывают пустыми, но большинство получают несколько элементов декора.
- При ломании одного блока стены ломается только выбранный блок. За проломом может появиться комната или длинный коридор с боковыми ответвлениями, соединяющими секции. Соседние блоки стены не сносятся.
- Пол и потолок нельзя ломать.
- При смерти в Backrooms сохраняются инвентарь и опыт; точкой возрождения служит кровать, если она задана, иначе запасная точка мира.

- Сундуки наполняются случайным лутом, причём таблица предметов различается для каждого уровня.

## Примечания
Генерация изменяет блоки внутри настроенного мира, поэтому тестируйте на резервной копии. Сборку следует проверить в GitHub Actions на вашей версии Paper перед установкой на основной сервер.
