# BackroomsPlugin v2.1 — Paper 1.21.4

## Установка
1. Собери проект командой `gradle build` (Java 21) или загрузи в GitHub и скачай артефакт из Actions.
2. Помести JAR в `plugins/` и перезапусти Paper.
3. В `plugins/Backrooms/config.yml` укажи точное имя существующего плоского мира в `world-name`.
4. Сделай резервную копию мира.
5. Выполни `/br generate`.

## Команды (только OP)
- `/br` — справка.
- `/br generate` — включить генерацию в выбранном мире.
- `/br stop` — остановить генерацию.
- `/br info` — показать статус.
- `/br level 0|1|2` — ручной переход для тестов.
Все команды требуют permission `backrooms.admin`, по умолчанию `op`.

## Порталы
В центральном чанке каждой зоны появляется портал из плачущего обсидиана и фиолетового стекла. Встань в проём, чтобы перейти на следующий уровень по циклу 0 → 1 → 2 → 0. Для теста также оставлена команда `/br level`.

## Чек-лист тестирования
1. Перезапусти сервер и проверь в консоли отсутствие ошибок загрузки.
2. OP: `/br info` — должен показать имя мира и состояние генерации.
3. OP: `/br generate` — генерация включается в существующем мире, новый мир не создаётся.
4. Подойди к центральной зоне и проверь коридоры, стены, пол, потолок и освещение.
5. Проверь портал на уровне 0: он должен перенести на уровень 1; затем уровень 2; затем уровень 0.
6. Проверь `/br level 0`, `/br level 1`, `/br level 2`.
7. Попробуй сломать стену: ожидается открытый проход. Попробуй сломать пол/потолок: событие должно отменяться.
8. Войди в Backrooms, проверь наличие кровати в обычном мире, умри: инвентарь и опыт должны сохраниться, возрождение должно пойти к кровати.
9. Зайди не-OP аккаунтом и попробуй все команды: ожидается отказ.
10. Выполни `/br stop`, перезапусти сервер и проверь `/br info`.

## Ограничения прототипа
Это тестовая версия. Генератор модифицирует блоки в существующем мире и строит по мере загрузки чанков. Не исследуй ценные постройки в выбранном мире; лучше использовать отдельный плоский тестовый мир. Сохранение уже созданных секций между перезапусками и устойчивое определение уровня у границ зон требуют дальнейшей доработки. Портал — физическая конструкция из обсидиана и стекла; переход срабатывает при касании стекла.
